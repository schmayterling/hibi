# Capture a quick note

Enable **Quick note** in **Settings → Addons**. Press `Cmd/Ctrl+Alt+N` while Hibi is running, or choose **Quick note: capture** from the command palette. The shortcut works while another application has focus.

Choose a destination in **Settings → Quick note**. Use the current workspace, select a recent workspace, or use **Choose workspace…** to select another folder as a workspace. Then choose its root or a folder. Set a default title, or turn on **Ask for a title** to enter one each time. You can change the global shortcut with an Electron accelerator such as `CommandOrControl+Alt+N`; clear it to use only the command palette. Save the settings to apply them.

Type your note in the capture window. Press **Save note** or `Cmd/Ctrl+Enter` to create a Markdown file. Hibi adds a number when a file with the same title already exists. Existing notes are never overwritten.

The shortcut is available while Hibi is running. On macOS, it can reopen Hibi after the last window closes. Quitting Hibi releases it.
