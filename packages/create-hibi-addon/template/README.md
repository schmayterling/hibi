# __HIBI_NAME_TEXT__

This addon adds **Say hello** to Hibi's command palette.

## Try it

Run `npm run check`, then choose **Install addon…** from Hibi's command palette and select this folder. Hibi installs reviewed addons disabled; enable it after installation.

## Share it

Commit `hibi-addon.json`, `index.js`, and this readme to a public HTTPS Git repository, or put them in a ZIP archive. Do not include `node_modules`.
