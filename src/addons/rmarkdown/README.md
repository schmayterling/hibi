# R Markdown

Turn on **R Markdown** in **Settings → Addons** to edit `.rmd` files. Write in source view or use side-by-side view for a preview. Install Pandoc 3.11 or newer for the preview. To run a document, also install R with the `rmarkdown` package and its Pandoc dependencies.

Choose **Run document** to execute the document and its project code, then export the result as HTML if needed. That code has your file and network access, so only run documents you trust. Embedded code does not run while you type.

Open **Settings → Dependencies** to check Pandoc and R, choose their executables, or install them with a supported package manager. **Manage dependencies** in the addon's settings opens the same page. Install R packages such as `rmarkdown` separately. See [Document formats](https://docs.hibi.garden/#page=editing%2Fformats.md) for more help.
