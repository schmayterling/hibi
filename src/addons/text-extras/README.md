# Text extras

Write subscript with `~subscript~`, as in `H~2~O`. Underline text with `__underline__`, as Discord does. Start a line with `-# small text` for Discord-style small text. This addon is on by default.

Subscript must stay on one line with no spaces next to the `~` characters. Use `~~text~~` for strikethrough. While underline is on, write bold as `**bold**`; turn underline off to read `__text__` as bold again. Press Enter after small text to start a normal paragraph.

Choose which features to use in **Settings → Syntax**.

Automatic flavor detection ignores examples inside code blocks and escaped syntax.
