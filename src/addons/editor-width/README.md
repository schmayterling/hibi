# Editor width

Enable **Editor width** in **Settings → Addon Manager** to show a slider alongside the other status bar items at the bottom of the editor.

Drag the slider to adjust the editing width from 320 to 1600 pixels. The default is 800 pixels. Changes apply immediately in Normal, Source, and side-by-side views, including split documents. You can also focus the slider and use the arrow keys, Home, or End. Resizing a sidebar keeps your chosen width; the editor only becomes narrower when the available pane cannot fit it.

Hibi remembers the width on this device and applies it to all documents. Disabling the addon restores the usual full width. The slider follows your status bar visibility setting under **Settings → Appearance**.

Inspired by [Editor Width Slider for Obsidian](https://community.obsidian.md/plugins/editor-width-slider).
