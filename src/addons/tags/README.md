# Tags

Tags are on by default. Write tags such as `#ideas` or `#work/project` in ordinary Markdown text, outside headings and code. You can turn Tags off in **Settings → Addons**.

Shift-click a tag or choose **Tags** from the sidebar view menu to find matching notes. Save new notes inside the workspace to include them in these results.

Hover over a matching note's name to see its full workspace path.
