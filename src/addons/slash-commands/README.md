# Slash commands

Type `/` at the start of a paragraph in normal view or a line in Markdown source to insert syntax. This addon is on by default. The menu follows enabled features under **Settings → Syntax**, including syntax added by addons. Some features appear only in source view.

Type a name or keyword to filter the menu. Use the arrow keys, then Enter or Tab, or click an item. Press Escape to close the menu.

With Vim enabled, use insert mode for slash commands; `/` searches in normal mode.
