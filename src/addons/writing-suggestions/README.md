# Writing suggestions

Enable **Writing suggestions** under **Settings → Addons**. While editing, type `#` followed by a tag prefix to complete a tag already used in the workspace. Type `;todo` to insert `TODO: ` in either editor view. In Source view, type `[[` followed by a note path prefix to complete a wiki-style note link.

Suggestions appear as you type or when you press `Ctrl+Space`. Choose one with Enter or Tab, or press Escape to leave the document unchanged. The addon does not scan note text itself; tag and path results come from Hibi's workspace query service.
